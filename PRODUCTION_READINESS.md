# Production Readiness Gate

## Application
- [ ] Build passes
- [ ] Typecheck/lint passes
- [ ] Health endpoint passes
- [ ] Authentication/authorization verified where applicable

## Data
- [ ] Migrations tested where applicable
- [ ] Persistence tested
- [ ] Backup/restore documented
- [ ] No business records rely on localStorage

## AI
- [ ] Gateway routing and fallback verified
- [ ] Tool scopes verified
- [ ] Evaluation suite passes
- [ ] Observability traces visible
- [ ] Token/call usage measured

## Integrations
- [ ] Real connector test passes
- [ ] Timeout/auth failure/empty result/partial result tested

## UX
- [ ] Real browser E2E passes
- [ ] Refresh persistence passes
- [ ] Error states understandable
- [ ] No dead buttons or placeholder business data shown as real

## Governance
- [ ] Architecture baseline valid
- [ ] ADRs created for approved changes
- [ ] Known limitations documented
- [ ] Production decision recorded
