# Source Authority Policy

| Priority | Source | Authority | Allowed use |
|---|---|---|---|
| 1 | Primary system of record | Highest | Final factual answer |
| 2 | Approved internal repository/API | High | Supporting evidence |
| 3 | Approved internal documents | Medium/High | Context |
| 4 | Public vendor documentation | Medium | External reference |
| 5 | Public web | Variable | Supplemental |

Rules:
- Resolve entity identity before combining results.
- Never silently merge conflicting sources.
- Label stale evidence.
- Missing evidence creates a visible coverage gap.
- `Not found` is different from `does not exist`.
