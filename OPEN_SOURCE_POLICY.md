# Open-Source Dependency Policy

This template is open-source-first and commercial-product-friendly.

## Default allowlist
Permissive licenses such as MIT, Apache-2.0, BSD-2/3-Clause, and ISC may be adopted after normal security and maintenance review.

## Requires explicit ADR + license review
GPL/LGPL, AGPL, SSPL, BSL, Elastic License, Sustainable Use License, source-available/modified licenses with SaaS, multi-tenant, branding, field-of-use or redistribution restrictions, and unknown/NOASSERTION licenses.

## Rule
Public source code on GitHub does not automatically mean a component is safe to embed in a commercial product.

For every architecture dependency record: repository, exact version/commit, license, commercial-use implications, self-hosting requirements, and replacement/exit strategy.
